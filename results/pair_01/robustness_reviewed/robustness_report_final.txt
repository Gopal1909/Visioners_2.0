2. METHOD AND CLEAN REFERENCE

Only Scan 1 is perturbed; Scan 0 remains the reference. C2C predicts changed when
nearest-neighbour Euclidean distance is strictly greater than
0.075 m. Scan 0 changed means removed; Scan 1 changed
means added; cd_type=0 means unchanged. There are 4,444,935 original Scan 0 points
and 5,089,793 original Scan 1 points (9,534,728 pooled observations).

The combined metric pools both scans into a directional three-class confusion
matrix (unchanged, removed, added). Macro F1 averages those three class F1s;
it is not the average of the two changed-class directional F1s. Unchanged points
from both epochs contribute observations; these are not unique physical sites.

Scan 0 removals: precision 0.5450, recall 0.6674, F1 0.6000, changed IoU 0.4286.
TP=358,760, FP=299,522, FN=178,811, TN=3,607,842.

Scan 1 additions: precision 0.6064, recall 0.7530, F1 0.6718, changed IoU 0.5058.
TP=572,572, FP=371,688, FN=187,790, TN=3,957,743.

Combined: macro F1 0.7359, macro mIoU 0.6046, overall accuracy 89.12%, unchanged F1 0.9358.
The fixed C2C threshold was selected by a Stage 2 sweep on this same pair.
These are pilot, in-pair selection results, not held-out or cross-scene evidence.

3. REGISTRATION PROTOCOL AND LIMITS

apply_rigid_transformation resets np.random.default_rng(42) on every call.
Translation-only uses the normalized first three-component Gaussian draw.
Rotation-only uses that first normalized draw as its axis. Rotation is about
center_p1 = np.mean(xyz1, axis=0), not the origin or sensor location.
Combined perturbations rotate first and then translate: the rotation axis uses
the first draw, while the translation direction uses the SECOND draw. Therefore
the translation-only and combined translation directions differ. At the clean
zero/zero condition no draw is consumed. Directions/axis are fixed within each
nonzero sweep, not averaged over random trials or opposite directions.

The previous final report's explicit translation vector was not established by
the code/CSV audit and is withdrawn. The approximate centroid in the inspection
report is historical metadata; this report uses the exact code definition rather
than an unlogged numerical centroid. Directions and centroid should be saved in
future run metadata. No alternate-axis runs were performed here.

Small perturbations improve some observed scores. This is a directional,
scene-specific result and does not establish improved reliability under unknown
registration error. A plausible explanation is altered nearest-neighbour
correspondences around closely spaced structures, but these aggregate CSVs do
not identify which surfaces moved across the decision boundary. Claims about
specific walls, new elements or opposite-direction outcomes are unverified.

Rotation displacement is 2*r_perp*sin(theta/2), approximately r_perp*theta for
small angles, where r_perp is distance to the rotation AXIS through the centroid.
It is not generally distance to the centroid or range from the scanner.
Nearest-neighbour distance also depends on geometry; exceeding the C2C threshold
in rigid displacement does not force every unchanged point to exceed it.

9. OCCLUSION: STRICT AND VISIBILITY-AWARE PROTOCOLS
Source: occlusion_metrics.csv.

Scan 1 points inside an XY cylinder (unbounded in Z) are removed. The main
routine explicitly passes center_p1 = mean(xyz1); the helper's median default
is not used. This is a synthetic spatial deletion, not sensor ray tracing.
The removed percentage is the fraction of points, not the fraction of site area.

Protocol A (strict false-alarm stress): evaluate ALL Scan 0 points against the
occluded Scan 1 and evaluate retained Scan 1 against original full Scan 0.
Original cd_type labels are retained, exposing false removals from missing data.
This is an all-point detection evaluation under missing coverage, not solely
a false-positive-rate metric.

Protocol B (visibility-aware mask): reuse exactly the same distances/predictions,
but exclude Scan 0 points inside the known synthetic cylinder from scoring.
Scan 1 scoring and its full Scan 0 search target are identical to Protocol A.
Only the evaluation population changes; the detector is not improved by this
mask. This oracle mask does not prove mutual visibility outside the cylinder.
Boundary effects, pre-existing holes and other occlusions can remain.

For the four families under strict occlusion scoring, the observed ordering of

With occlusion B, noise degrades more than occlusion B. The ranking depends on
protocol, stress ranges, geometry and the evaluated population. Centimetres,
degrees, retention fractions and deletion radii are not matched physical stress
levels, so this is not a universal robustness ranking or a significance test.
