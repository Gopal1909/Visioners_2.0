1. METHOD DESCRIPTION & FORMULATION
------------------------------------
Cloud-to-Cloud (C2C) distance thresholding is the canonical geometric baseline for
point-cloud change detection. For two co-registered point clouds P0 (Epoch 0, t0) and
P1 (Epoch 1, t1):

1. Forward Direction (P0 -> P1):
   For each point p_i in P0, the nearest-neighbor Euclidean distance is calculated as:
       d_{0->1}(p_i) = min_{q_j in P1} ||p_i - q_j||_2
   A point is classified as changed (removed) if d_{0->1}(p_i) > tau.

2. Reverse Direction (P1 -> P0):
   For each point q_j in P1, the nearest-neighbor Euclidean distance is calculated as:
       d_{1->0}(q_j) = min_{p_i in P0} ||q_j - p_i||_2
   A point is classified as changed (added) if d_{1->0}(q_j) > tau.

3. Combined Directional 3-Class Interpretation:
   - Points in P0 with d > tau -> Removed (Class 1)
   - Points in P1 with d > tau -> Added (Class 2)
   - Points in either cloud with d <= tau -> Unchanged (Class 0)

2. UNDERLYING ASSUMPTIONS & THEORETICAL LIMITATIONS
--------------------------------------------------
A. Core Assumption:
   C2C assumes that unchanged surfaces are densely and uniformly sampled in both scans,
   such that any point on a static surface in Epoch t0 finds a corresponding point in Epoch
   t1 within the sensor's sampling resolution (approx. 2 cm for this Livox Mid-360 MLS scanner).

B. Major Limitations in Construction Environments:
   1. Point Density & Range Variations: MLS point density decreases quadratically with
      distance from the scanner path and degrades on surfaces viewed at grazing angles.
      Sparsely sampled static surfaces produce artificially large C2C distances (>5 cm),
      generating false positives without any physical change.
   2. Occlusions & Shadowing: Equipment, workers, or newly delivered materials cast
      occlusion shadows. Points on static surfaces behind these occlusions in one scan
      have no counterparts in the other scan, falsely triggering change detections.
   3. Lack of Orientation/Normal Awareness: Unlike M3C2, C2C ignores local surface normals.
      Consequently, C2C measures orthogonal distance to the closest point anywhere in space,
      making it vulnerable to tangential sampling noise and edge artifacts.
   4. Sensitivity to Registration Jitter: While global co-registration is verified
      (median static error 1.64 cm), localized SLAM drift or vibration causes boundary
      pixels along building edges to exceed centimetre thresholds.
   5. No Semantic Context: Distance alone cannot distinguish temporary construction
      equipment (scaffolding, containers, vehicles) from permanent structural changes
      (columns, slabs, walls).

6. KEY FINDINGS & STAGE 3 IMPLICATIONS
--------------------------------------
1. Trade-off Characteristic: Small thresholds (1-3 cm) capture almost all real changes
   (Recall > 90%), but suffer severe false positive rates (Precision 24-37%) because
   sensor sampling noise (~2 cm) exceeds the threshold on static surfaces.
2. Large thresholds (> 10 cm) eliminate false positives (Precision > 65%), but miss thin
   structural elements, fences, and subtle ground elevation modifications (Recall drops to 55-64%).
3. The optimal compromise on this MLS pair is around 7.5 cm (F1 ~ 0.60 for removals, 0.67 for additions).
4. Next Stage Goal: Demonstrate how surface normal projection (M3C2) and robust neighborhood
   confidence intervals suppress tangential noise and improve change detection reliability.
