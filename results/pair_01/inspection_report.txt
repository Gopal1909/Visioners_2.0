6. DATASET FORMAT ISSUES & HANDLING
-----------------------------------
- PLY Element Header Convention:
  The dataset headers define 'element params <N>' instead of standard 'element vertex <N>'.
  Native Open3D C++ loader ('o3d.io.read_point_cloud') expects 'element vertex' and returns 0 points.
  Resolution: Use 'plyfile' or NumPy structured array to load attributes, then wrap in
  'open3d.geometry.PointCloud(o3d.utility.Vector3dVector(xyz))'. This is fully robust
  and preserves all custom scalar fields (intensity, cd_type).
